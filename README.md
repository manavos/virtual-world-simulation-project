# Virtual World Simulation Project

## Project Overview:
A simulation of a dynamic virtual world where entities interact with the environment and move autonomously using A* pathfinding. (built off code from Prof. Rivera at Cal Poly)

## Core Features:

Entity movement powered by A* pathfinding algorithm for efficient navigation.

Use of the Strategy design pattern to refactor movement behaviors and improve code maintainability.

Simulation includes a variety of entities with unique behaviors and interactions within the world.

## World Events:

Implemented world-changing events that dynamically affect the simulation (e.g., environmental changes, entity behavior alterations).

Entity reactions to these events are determined by their state and environment.
